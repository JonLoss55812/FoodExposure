# Frontend fix — 2026-10-26 (v0.5.231 → v0.5.233)

Baseline: 1059 tests / 70 suites passing, `tsc --noEmit` clean.
After: 1065 tests / 70 suites passing, `tsc --noEmit` clean.

## Fixed

### 1. Coloured pill labels failed WCAG AA contrast (v0.5.232)

Stage badges and "Safe Food" badges on every Foods-list row (`FoodCard`), plus the category
and "Safe Food" tags on food detail, drew their label **in the pill's own hue** over a
12.5% tint of that hue. The ratios, computed with the same WCAG formula as
`contrast.test.ts`:

| Hue | Light: label on its tint | Dark: label on its tint |
|---|---|---|
| Eat `#34D399` | 1.76 | 5.92 |
| Fruit `#F59E0B` | 1.95 | 5.46 |
| Success `#22C55E` | 2.05 | 5.13 |
| Tolerate `#94A3B8` | 2.31 | 4.60 |
| Grain `#D97706` | 2.79 | 3.94 |
| Protein `#EF4444` | 3.20 | 3.50 |
| Dairy `#3B82F6` | 3.18 | 3.40 |
| Other `#6B7280` | 4.13 | 2.67 |

All are 12–14px text, so they need 4.5:1. The contrast suite missed this because it only
checks theme tokens, and these hues come from `STAGE_CONFIG` / `CATEGORY_CONFIG`.

Fix: the label is now `theme.colors.text` (≥15:1 on every tint). The tint and emoji still
carry the hue, so stages and categories stay colour-coded. The food-detail safe tag also
lost its two hardcoded `#22C55E` literals. +2 tests assert the computed label colour; each
fails when its source file is reverted.

### 2. Header Back / Cancel links were ~20px tap targets (v0.5.233)

This was left open by frontend-2026-10-05. It covered Add Food, Food Detail (loaded and
not-found), Add Child and Edit Child. Each link now has `minHeight`/`minWidth: 44`,
`alignSelf: 'flex-start'`, and the header's `paddingTop` drops 60 → 48 so the text stays
where it was. Side effect: the screen title sits about 12px lower. +4 tests assert the
computed min-height; all fail when the source is reverted.

## Seen, not done

- `placeholderTextColor="#94A3B8"` is hardcoded in six inputs (foods, join ×2, log ×2,
  food/add). It is 2.56:1 on white. Placeholders are exempt from AA when a visible label
  exists, but some of these inputs (Search foods) have no visible label. Fix: a theme token
  such as `textTertiary`.
- The contrast suite should also check `STAGE_CONFIG`/`CATEGORY_CONFIG` hues wherever they
  are used as text or icons, so a future label in a hue gets caught.
- No redesign is warranted. The visual language is consistent.
