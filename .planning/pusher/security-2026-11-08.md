## Still open (since 2026-09-27)

### HIGH (latent), 9/10: every `convex/` function is unauthenticated

`grep -c ctx.auth convex/*.ts` returns 0 for every file, and `convex/` has had no commits since the last
audit. Any caller can pass any id, for example `children.remove({id})`,
`exposures.getByFamily({familyId})` or `families.getByInviteCode`. That is an IDOR across every family's
children and feeding history. **It is not exploitable today because nothing is deployed and `app/`
never calls Convex.** But wiring Convex is still CLAUDE.md's standing next priority. **Do not
`npx convex deploy` these files as they are.** The remediation in `security-2026-09-27.md` §1 still applies:
derive the family from `ctx.auth.getUserIdentity()` server-side, and never trust a client-supplied `familyId`.
