## Fixed: tap targets under 44pt

v0.5.154 added a 44pt floor to the chip and Button styles. It did not cover text-only
pressables, or the separate `themeChip` style in Settings.

| Surface | Before (approx.) | Why it matters |
|---|---|---|
| Settings → Family: Rename / Delete per child | ~17pt | Delete is destructive and sits one 16pt gap from Rename |
| Settings → Family: inline rename Save / Cancel | ~17pt | |
| Settings: Theme chips, Feeding Profile chips | ~25pt | The profile sets the 15/20/30 acceptance threshold |
| Food detail: rename Save / Cancel | ~20pt | |
| Food detail: exposure notes / date editor Save / Cancel | ~20pt | |

Each now has `minHeight: 44` and `justifyContent: 'center'`. Nothing else about the look
changed.

## Harness finding (worth knowing)

CLAUDE.md said tap-target sizes could not be asserted under jsdom. That is only half
true. There is no computed *layout*, but react-native-web emits `minHeight` as a CSS
class, and `getComputedStyle(el).minHeight` returns `'44px'`. I added 4 tests that assert
this on every fixed action. Reverting the two source files makes all 4 fail. I updated
CLAUDE.md's Important Notes to say this.
